# What If Prism — سیستم تولید YouTube Shorts

کانال Shorts داستانی «چه می‌شد اگر»، متمرکز بر **بدن انسان، مغز، حواس و مرزهای تجربه‌ی انسانی**.

---

## از کجا شروع کنم؟

| می‌خواهم... | برو سراغ |
|---|---|
| قوانین قفل‌شده را ببینم | **`CANON.md`** |
| یک قسمت جدید بسازم، با کنترل در هر مرحله | **`01-...-v4.md`** |
| ببینم یک قسمت کامل چه شکلی است | **`02-VIDEO-01-...-v2.md`** |
| یک قسمت را یکسره و خودکار بسازم | **`03-ONE-SHOT-...-v2.md`** |
| بفهمم چرا این تغییرات انجام شد | **`00-REVIEW-...md`** |

---

## فایل‌ها

```
CANON.md                          ← تنها منبع حقیقت. قوانین قفل‌شده.
├── 01-...-MASTER-PROMPT-v4.md    ← کارخانه (مرحله‌به‌مرحله، برای چت)
├── 02-VIDEO-01-...-v2.md         ← محصول (قسمت ۰۰۱، خروجی واقعی)
└── 03-ONE-SHOT-...-v2.md         ← کارخانه (یکسره، برای ایجنت)

00-REVIEW-بررسی-و-اصلاحیه.md      ← گزارش بازبینی فنی نسخه‌ی اول
04-CORRECTION-PROMPT.md           ← پرامپت اصلاحیه (آرشیو — اعمال شد)
tools/check-canon.py              ← اعتبارسنج خودکار
```

### فرق ۰۱ و ۰۳

**جایگزین همدیگرند، نه مکمل.** هر دو یک سیستم‌اند با یک تفاوت: کجا اجازه‌ی دخالت داری.

| | ۰۱ — MASTER PROMPT | ۰۳ — ONE-SHOT |
|---|---|---|
| جریان | با کلمات کلیدی: شیت ← تصویر ← ویدیو ← صدا ← انتشار | بدون توقف تا انتها |
| اصلاح | بعد از هر مرحله | فقط در پایان |
| مناسب | چت معمولی | ایجنت با تولید تصویر و TTS |
| کیفیت | بالاتر | سریع‌تر |

**توصیه:** ۵ قسمت اول با فایل ۰۱ (هنوز داری استایل را کالیبره می‌کنی)، بعد از تثبیت برو سراغ ۰۳.

---

## چرا CANON جدا است؟

در نسخه‌ی اول، قوانین قفل‌شده در هر سه فایل کپی شده بودند. نتیجه:

- امضای برند (PRISM TRANSITION) **سه متن متفاوت** داشت — حتی `center` و `centre` فرق داشت
- جدول زمان‌بندی **دو نسخه‌ی ناسازگار** داشت (هوک ۴ ثانیه در برابر ۹ ثانیه)
- فایل ۰۱ حتی با **خودش** تناقض داشت

یک قانون که در سه جا کپی شود، به مرور سه قانون متفاوت می‌شود. حالا هر سه فایل به `CANON.md` ارجاع می‌دهند.

---

## اعتبارسنجی

```bash
python3 tools/check-canon.py
```

۲۴ بررسی خودکار: یکسان بودن STYLE LOCK و PRISM با CANON، نبودن علامت ممنوع در TTS، سرعت هر پلان، مدت کل، افشای AI، قرارداد نام‌گذاری، و تاریخ سیاست یوتیوب.

بعد از **هر** ویرایش روی این فایل‌ها اجرایش کن.

## قوانین کلیدی

| قانون | مقدار | مرجع |
|---|---|---|
| مدت ویدیو | ۵۵–۵۹ ثانیه | `CANON §3` |
| فرمول پلان | `کلمات ÷ 2.75 + 0.45` | `CANON §4` |
| سرعت هر پلان | ۲.۲–۲.۷ w/s — **هر پلان جداگانه** | `CANON §4` |
| تعداد پلان | ۹–۱۳ | `CANON §4` |
| ناحیه‌ی امن | ۹۰۰×۱۳۵۰ مرکز فریم | `CANON §6` |
| بلندی صدا | −۱۴ LUFS | `CANON §8` |
| PRISM | دقیقاً یک بار، روی «What if» | `CANON §2` |
| شکست الگو | هر ۴ ویدیو یک‌بار | `CANON §13` |

**سه دام رایج:**

1. **میانگین سرعت معیار نیست.** ممکن است میانگین ۲.۶ باشد ولی پلان اول ۳.۶۷ و دومی ۱.۶۷.
2. **علامت `|` در هیچ TTS‌ای کار نمی‌کند.** و `...` مکث با طول مشخص نمی‌سازد.
3. **ستون ۱۲۰ پیکسلی سمت راست.** اگر سوژه سمت راست باشد، دکمه‌ی سابسکرایب روی صورتش می‌نشیند.
